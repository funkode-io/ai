# funkode / ai

Tooling for running AI coding agents day to day.

| Path | What it is |
| --- | --- |
| [`herdr/status-bar`](herdr/status-bar) | Herdr plugin: tab-bar segments for the active treehouse worktree, agent context consumption, and PR number. |

## Herdr plugins

Install straight from this repo:

```bash
herdr plugin install funkode-io/ai/herdr/status-bar
```

Or, while developing, link a checkout:

```bash
herdr plugin link ~/git/ai/herdr/status-bar
```
